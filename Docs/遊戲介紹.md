# 這是一款什麼遊戲？

| | |
|---|---|
| **類型** | 回合制卡牌對戰（單人闖關 + 劇情引導） |

## 一場對戰，五個瞬間

<div class="timeline">
<div class="tl"><span class="tl-n">1</span> <strong>開局</strong>：擲骰決誰先攻，雙方英雄 20 血，起手 5 張牌。</div>
<div class="tl"><span class="tl-n">2</span> <strong>出牌</strong>：打出怪獸到場上，或施放火球、治療、凝視等法術。</div>
<div class="tl"><span class="tl-n">3</span> <strong>讀盤</strong>：看對手意圖與教練提示，決定要擋還是要攻。</div>
<div class="tl"><span class="tl-n">4</span> <strong>變天</strong>：一般對戰中盤起，場地效果改變傷害／治療等規則（入門關沒有）。</div>
<div class="tl"><span class="tl-n">5</span> <strong>結算</strong>：一方英雄歸零即分勝負；勝利後可看每張怪的熟練度進度。</div>

# 同一張牌，越打越懂

| 階段 | 卡面上看到 | 你的感覺 |
|------|-----------|----------|
| **剛認識** | 只有攻擊力／血量 | 「先學會出牌就好」 |
| **熟了** | 多一行戰技摘要（且已生效） | 「原來還有這招！」 |
| **精通** | 完整規則可長按查看 | 「這張牌我真正懂了」 |

> 國王、王后、民兵一開始就是完整版，方便你對照「解鎖後長什麼樣」；其他怪物牌會隨對戰慢慢成長。
